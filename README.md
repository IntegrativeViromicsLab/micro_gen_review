# Evolving Strategies for Virus Discovery

This repository contains scripts used to generate the summarized tables and figures presented in the manuscript “Evolving Strategies for Virus Discovery” (under review, Microbial Genomics, in press). The analyses are based on an aggregated dataset of 502 genome-resolved virome studies (2010–early 2026) and 95 viral detection tools.

Supplementary Table 2 summarizes viral detection studies published between 2010 and 2026. It includes metadata such as authorship, publication year, data source, environmental origin and classification, viral nucleic acid type (DNA or RNA), number of de-replicated viral operational taxonomic units (vOTUs), and the assembly and viral identification tools used.

Supplementary Table 3 provides an overview of viral identification tools included in this study. It compiles key attributes such as publication year, most recent update, authorship, methodological approach, targeted viral types (all viruses, DNA viruses, or RNA viruses), and functional capabilities including taxonomy assignment, genome annotation, and host prediction. It also includes source code availability and citation counts (retrieved from Google Scholar in March 2026).

More details will be available upon publication of the manuscript.

Andrade AAS, Silverj A, Josephs T, Gregory A. Evolving Strategies for Virus Discovery (in press)
